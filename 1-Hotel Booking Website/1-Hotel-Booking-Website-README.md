# Movenpick Hotel Booking Website

A front-end hotel reservation website built with pure HTML and CSS, designed as a booking flow concept for the Movenpick Hotel Cairo. It walks a guest through searching for a room, browsing options, and confirming a reservation.

## Preview

A demo video and thumbnail are included in the `Demo/` folder.

## Pages

| Page | Description |
|---|---|
| `index.html` | Landing page with a room search form (check-in, check-out, guests, preferences) |
| `Rooms.html` | Full catalog of all available room types with photos and pricing |
| `results.html` | Filtered room results based on the search query |
| `book.html` | Booking form for guest details, room selection, and payment |
| `success.html` | Booking confirmation page |
| `contactus.html` | Contact form and hotel address details |

## User Flow

```
index.html -> results.html -> book.html -> success.html
                  |
              Rooms.html
                  |
             contactus.html
```

## Available Room Types

- Sea View Queen Bed Room - 3,000 EGP/night
- Sea View Honeymoon Suite - 5,000 EGP/night
- Sea View Double Bed - 3,000 EGP/night
- Garden View Chalet - 7,000 EGP/night
- Garden View King Bed - 2,500 EGP/night
- Pool View Double Bed - 3,500 EGP/night

## Tech Stack

- **HTML5** - semantic markup, forms, tables, metadata
- **CSS3** - layout and styling (`style.css`)
- No CSS frameworks or JavaScript - pure HTML/CSS only
