## Overview

### The Challenge

Build a recipe page for a "Simple Omelette Recipe" that matches the provided design, including:

- A hero image and recipe description
- A preparation-time callout box
- Ingredients and step-by-step instructions
- A nutrition table
- A responsive layout for mobile and desktop

## Process

### Built With

- Semantic HTML5 markup (`main`, `header`, `aside`, `section`, `ol`, `table`)
- CSS3 with custom properties
- Flexbox for page centering
- `@font-face` with two custom fonts (Young Serif for headings, Outfit for body text)
- Mobile-first workflow

### What I Learned

Key takeaways from this build:

- Structuring a real-world content page (not just a card) with distinct semantic sections for prep time, ingredients, instructions, and nutrition
- Styling an ordered list of numbered cooking steps
- Building a simple two-column nutrition table with `<table>`/`<tr>`/`<td>`
- Loading and pairing two different custom fonts with `@font-face`
