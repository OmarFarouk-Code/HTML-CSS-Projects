# HTML-CSS-Projects

A collection of front-end projects built while learning and practicing HTML and CSS - ranging from a full multi-page website concept to solutions for [Frontend Mentor](https://www.frontendmentor.io/) component challenges.

Each project lives in its own numbered folder and has its own README with details on the build, what was learned, and (where relevant) links to the design files and live demo.

## Projects

| # | Project | Description | Tech |
|---|---|---|---|
| 1 | [Hotel Booking Website](./1-Hotel%20Booking%20Website) | Multi-page hotel reservation flow for the Movenpick Hotel Cairo - search, browse rooms, and book | HTML, CSS |
| 2 | [Specialty Coffee Website](./2-Specialty%20Coffee%20Website) | Multi-page site for a coffee shop brand: story, menu, locations, and an order form | HTML |
| 3 | [QR Code Component](./3-QR%20Code%20Component) | Frontend Mentor solution - a simple QR code card component | HTML, CSS |
| 4 | [Blog Preview Card](./4-Blog%20Preview%20Card) | Frontend Mentor solution - a blog post preview card | HTML, CSS |
| 5 | [Social Links Profile](./5-Social%20Links%20Profile) | Frontend Mentor solution - a dark-themed social links profile card | HTML, CSS |
| 6 | [Recipe Page](./6-Recipe%20Page) | Frontend Mentor solution - a recipe page with ingredients, instructions, and a nutrition table | HTML, CSS |

## Purpose

This repo tracks progress from larger, self-directed builds (the hotel and coffee shop sites) toward focused, design-matched component challenges from Frontend Mentor - practicing semantic HTML structure, the CSS box model, Flexbox layout, custom fonts, and responsive design.

## Tech Stack

- **HTML5** - semantic markup across all projects
- **CSS3** - custom properties, Flexbox, `@font-face` for custom fonts
- No CSS frameworks or JavaScript unless noted in an individual project's README
