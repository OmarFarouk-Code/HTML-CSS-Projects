## Overview

### The Challenge

Build a dark-themed social links profile card that matches the provided design, including:

- A profile card with avatar, name, location, and short bio
- A stacked list of social link buttons (GitHub, Frontend Mentor, LinkedIn, Twitter, Instagram)
- Hover and focus states for all interactive elements
- A responsive layout for mobile and desktop

## Process

### Built With

- Semantic HTML5 markup
- CSS3 with custom properties
- Flexbox for centering the card and stacking the link list
- `@font-face` with a variable font (Inter)
- Mobile-first workflow

### What I Learned

Key takeaways from this build:

- Styling a dark UI with HSL color values for backgrounds, text, and accent colors
- Building a reusable list of link "buttons" from a plain `<ul>`/`<li>` structure
- Using `border-radius` percentages to shape the avatar image
- Centering a fixed-width card both vertically and horizontally with Flexbox
