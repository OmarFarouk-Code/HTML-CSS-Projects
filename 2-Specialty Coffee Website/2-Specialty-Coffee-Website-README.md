# Koffee Kulture - Specialty Coffee Website

A multi-page website concept for Koffee Kulture, a specialty coffee shop and cafe. The site covers the brand story, a full drinks menu, branch locations, and an online order form, built with plain semantic HTML.

## Pages

| Page | Description |
|---|---|
| `pages/index.html` | Home page with the KK Story and KK Koncept brand sections |
| `pages/menu.html` | Full drinks menu (cold and hot drinks) laid out in tables with descriptions, sizes, and pictures |
| `pages/locations.html` | Branch locations with working hours and Google Maps directions links |
| `pages/order.html` | Order form for drink, size, milk choice, add-ons, and special requests |

## Features

- Shared header/nav across all four pages (Home, Locations, Menu, Order)
- Menu presented as structured HTML tables with item, description, sizes, and photos
- Order page built with real HTML form controls: text/tel inputs, a drink and size `<select>`, radio buttons for milk choice, and checkboxes for add-ons

## Tech Stack

- **HTML5** - semantic markup (`header`, `nav`, `article`, `section`, `table`, `form`)
- No CSS yet - this project currently focuses on HTML structure and content only
- No JavaScript
