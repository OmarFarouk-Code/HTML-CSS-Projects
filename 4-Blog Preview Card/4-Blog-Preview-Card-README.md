## Overview

### The Challenge

Build a blog preview card that matches the provided design, including:

- A clean card layout with an illustration, category badge, publish date, title, description, and author avatar
- Hover and focus states for the interactive blog title link
- A responsive layout that looks good on both mobile and desktop

## Process

### Built With

- Semantic HTML5 markup
- CSS3 with custom properties
- Flexbox for centering and layout
- `@font-face` with a variable font (Figtree) for typography
- Mobile-first workflow

### What I Learned

This challenge reinforced a few core front-end fundamentals:

- Loading and applying a variable font with `@font-face` and a weight range (`font-weight: 300 900`)
- Building a card component with a drop-shadow border effect using `box-shadow`
- Structuring a card's content hierarchy (badge, meta info, title, description, author) with plain semantic HTML
- Centering a single component on the page using Flexbox on the `body`
